VINAY FURNITURE - single page website
=====================================
EASIEST: double-click index.html (no install, no npm needed).

OPTIONAL local server (also no install needed, only Node.js):
  npm run dev      -> opens at http://localhost:5173

Replace photos: put your own HD photos in the images/ folder using the SAME file names
(hero, living, bedroom, dining, office, wardrobe, tv, sofaset, pooja, tables, foyer, kids, about, joinery, gallery, plant, a1-a3 - all .jpg).
Edit phone / email / address in index.html (search "98765").
