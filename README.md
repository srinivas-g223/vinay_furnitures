# Vinay Furniture

A responsive, single-page furniture storefront built with plain HTML, CSS, and JavaScript.

## Run locally

Requires Node.js:

```sh
npm run dev
```

Open <http://localhost:5173>. The site can also be opened directly from `index.html`.

## Update store details

Edit the phone number, email address, and showroom address in `index.html`. Furniture photos are in `images/`.
